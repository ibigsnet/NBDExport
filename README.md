**NBD Export**

Export a disk or partition as a **Network Block Device** (NBD) and pull remote NBD targets to qcow2/raw on Unraid. **Settings → Network Services → NBD** (tabs: Status · Host · Pull · Settings). Prefer private binds (Thunderbolt Net IPs when available). Read-only by default. Standalone — Thunderbolt Net and Fabric Routing (FRR) are optional companions.
