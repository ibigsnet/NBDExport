# Contributing

Bug reports, docs fixes, and pull requests are welcome.

1. Open an [issue](https://github.com/ibigsnet/NBDExport/issues) for discussion when the change is large.
2. Prefer focused PRs against `main`.
3. Test Host and Pull paths when you change export or imaging code.
4. Keep safe defaults: read-only Host and private bind IPs unless the user opts in.

Support: Unraid forum thread linked from the plugin’s Apps card.
